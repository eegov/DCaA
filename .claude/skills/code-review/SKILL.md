# Ревью в чистом контексте

Субагент `reviewer` видит только репозиторий и текст задачи. Пересказ того, что и почему сделано,
превращает свежий взгляд в согласие с автором, поэтому задача передаётся строго по шаблону, без объяснений
и списка исправленного.

## Порядок
1. Запусти субагента `reviewer` с задачей ровно такого вида и ничем больше:
   ```
   Режим: ревью. Ветка: <ветка>, база: dev. Раунд: <N>.
   Отчёт: допиши в docs/reviews/<ветка, где / заменён на ->.md, прошлые раунды не меняй.
   ```
2. Исправь все blocker и major. По каждому minor реши сам и допиши под таблицей раунда строку
   «не исправлено, потому что ...», если не исправляешь.
3. Повторяй шаги 1–2, пока есть blocker или major, но не больше трёх раундов.
   Если после третьего раунда они остались, остановись и покажи отчёт пользователю.
4. Запусти `reviewer` в режиме схлопывания:
   ```
   Режим: схлопывание. Ветка: <ветка>, база: dev.
   Отчёт: допиши в docs/reviews/<ветка, где / заменён на ->.md, прошлые раунды не меняй.
   ```
   Убери то, что он нашёл лишним, и снова `./mvnw verify`.
5. Закоммить отчёт: `docs(review): add review report for <ветка>`.

## Чего не делать
- Не переписывай отчёт ревьюера своими словами и не удаляй из него замечания.
- Не проводи ревью сам в текущем контексте вместо субагента.
