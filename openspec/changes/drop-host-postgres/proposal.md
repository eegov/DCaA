# Proposal

## Why

Задание лабы 1 начинается с «Поднять БД в контейнере», а для ПО просит два режима: локальная работа с этой базой
и запуск в контейнере в одной Docker-сети с ней. Спецификация `service-runtime` разрешает ещё и третий режим,
PostgreSQL, установленную на хост, без Docker. Задание его не требует, а правило проекта «делаем только текущую лабу»
запрещает функции сверх требований.

Решение пользователя: убираем режим «без Docker» через OpenSpec? → Да.

Решение пользователя: тестовые данные заливать через psql на хосте или через контейнер? → Через контейнер;
psql на хосте задание не требует, поэтому команд для него в README не нужно.

## What Changes

- Требование «Локальный запуск» со сценарием «Без Docker» заменяется требованием «Локальный запуск с БД в контейнере»:
  сервис на хосте, PostgreSQL только в Docker-контейнере. Замена, а не правка, потому что OpenSpec не даёт MODIFIED
  отбрасывать сценарии.
- Удаляется `docs/sql/create-local-db.sql`: он нужен только режиму без Docker.
- README: убираются режим «Без Docker», абзац о запуске с установленной PostgreSQL через `DB_PORT=5432`
  и PostgreSQL из списка того, что нужно установить.
- README, «Как заглянуть в БД»: psql запускается внутри контейнера `db` (`docker compose exec`), тестовые данные
  копируются в контейнер и заливаются там же. Таблица режимов, команды psql с хоста и подсказки к ним убираются.
- `docs/sql/seed-students.sql`: шапка описывает запуск через контейнер.
- `CLAUDE.md`: из ловушки про занятый порт 5432 убирается пометка «(режим без Docker)».

### Modified Capabilities
- `service-runtime`: локальный запуск больше не допускает PostgreSQL, установленную на хост.

## Out of scope

- Код сервиса, `compose.yaml` и тесты: сервису всё равно, кто слушает порт БД.
- `.env.example`: подсказка «если 5432 занят, поставьте 55432» остаётся, порт может занять любая программа на хосте.
- Архив `2026-11-20-lab1-students-service`: OpenSpec не правит архивированные изменения, новое поведение
  попадает в `openspec/specs/` при архивации этого изменения.

## Impact

Документация и спецификация: `openspec/specs/service-runtime/spec.md` (через archive), `README.md`, `CLAUDE.md`,
шапка `docs/sql/seed-students.sql`, удаление `docs/sql/create-local-db.sql`. Поведение сервиса и сборка не меняются.
